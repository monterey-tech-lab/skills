# Report template

ALWAYS use these sections for Step 1. Omit a section only if marked optional and say why.

```markdown
# Enhance-product report: {Product}

- **Role:** owner | competitor-check | studio/client
- **Subject:** {name} — {URL}
- **Date:** {YYYY-MM-DD}
- **Signal quality:** strong | mixed | sparse
- **Step:** 1 research complete — Step 2 not started | ready for selected IDs: …

## 1. Product map
Features, services, core traits, advantages (table OK). Cite product pages.

## 2. Competitors
Peer set (3–5) + offerings matrix (positioning, features, pricing signal, quirks).
Gaps derived from the matrix.

## 3. Voice of customer
Themes (praise + friction) with citations. Or **sparse-signal** note + proxy sources.

## 4. Ranked backlog (RICE)
Table: ID | Title | Type | Evidence | R | I | C | E | RICE | Notes
Sorted by RICE (note overrides).

## 5. AI enhancements
Only ideas that map to backlog IDs. For each: all six fit-audit answers (named gap, reduce total effort, beat current method, catchable errors, measurable outcome, year-ahead skill).

## 6. Founder lens
Which heuristic(s) applied and how they changed ranking or non-goals.

## 7. Non-goals
Explicit cuts (peer features we will not chase and why).

## 8. Step-2 handoff (if requested)
Selected IDs, success metrics, access needed, handoffs to craft-and-taste / security / ai-security if relevant.
```
