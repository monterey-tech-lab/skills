# Craft and Taste

Simple skill that encodes product craft and taste for AI agents: necessity and focus, calm UI hierarchy, purposeful motion, and first-class empty/loading/error/success states. Doctrine draws from Apple Human Interface Guidelines, Linear craft essays, Vercel design restraint, and publicly attributable Jobs-era focus principles.

## Install

```bash
npx skills add monterey-tech-lab/skills --skill craft-and-taste
```

Manual: copy `skills/craft-and-taste` to `~/.claude/skills/`, `.agents/skills/`, or `~/.cursor/skills/`.

## Structure

- `SKILL.md` — entry point (operating loop, hard rejects, branch pointers)
- `references/` — product necessity, UI craft checklist, motion, layout, build defaults, sources
