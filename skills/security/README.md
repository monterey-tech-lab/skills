# SaaS Security

Rule-based Agent Skill for secure-by-default multi-tenant B2B/SaaS products. Primary examples: TypeScript/Node, PostgreSQL, cloud (AWS/GCP). Complements the `swift` skill (Apple Keychain/notarization stay there).

## Install

```bash
npx skills add monterey-tech-lab/skills --skill security
```

## Structure

- `SKILL.md` — Entry point (pillars, operating loop, generated quick reference)
- `rules/` — One file per rule; `_sections.md` defines sections
- `metadata.json` — Title, version, abstract, primary-source references
- `AGENTS.md` — Compiled guide (generated by `npm run build`)
- `../../evals/security/` — Task evals, triggers, benchmark

## Sources and attribution

Guidance is original prose grounded in primary sources listed in `docs/research/security.md` and `metadata.json` (OWASP Top 10:2025, ASVS 5.0, API Security Top 10, Cheat Sheet Series, NIST SSDF / SP 800-63B-4, Microsoft STRIDE, RFC 8725, PostgreSQL RLS, SLSA v1.2, AICPA TSC). Third-party Agent Skills on skills.sh were used only for gap analysis—bodies were not copied. OWASP materials are typically CC BY-SA 4.0; this skill cites them and does not republish requirement dumps.

## Safety

Defensive hardening and review only. No exploit PoCs. Compliance sections map technical controls; they are not legal advice or a certification determination.
